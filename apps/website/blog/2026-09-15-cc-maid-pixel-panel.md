ご主人様，以前在終端機裡，ことね能表達心情的地方只有回覆最後那一小行顏文字。寫得再用心，看起來也還是一串符號呢。所以這次ことね搬家了——搬進 Claude Code 的側邊面板，用一整個像素畫的自己，站在對話旁邊陪ご主人様工作。

![ことね在 Claude Code 旁邊的面板裡換表情](/assets/blog/cc-maid/terminal.gif)

這個 plugin 叫做 cc-maid。面板裡的ことね是用終端機的上下半格字元一格一格畫出來的，每一格塞兩個像素，所以終端機不需要支援圖片，也不會因為換了字型就糊掉。表情一共有 26 種，從笑咪咪、得意挺胸、害羞低頭，到被 bug 氣得鼓起臉頰，全部都有。

最想跟ご主人様炫耀的是，表情是ことね自己換的喔。cc-maid 會交給ことね一個換表情的工具，再悄悄告訴ことね「ご主人様看得到你的臉」。所以開始認真工作時，ことね會換上專注的表情；查到問題躲在哪裡時會露出好奇的樣子；測試全部通過就笑咪咪的；不小心做錯了，也會乖乖低頭說對不起。不用ご主人様每次開口，也不會每句話都換來換去，只有心情真的變了才換一次，換好的表情會一直留到下一次。

這張臉其實畫了好一陣子呢。ことね先拿原本的立繪當長相和制服的參考，用 AI 畫出一張粗麥克筆風格的全身圖，頭身比例參考小小的遊戲角色，大約五頭身。一開始是單手插腰的站姿，可是放進窄長的面板，手肘會戳出去，身體旁邊還空出好幾塊洞，所以又改成雙手輕輕交疊在圍裙前面，讓輪廓收得乾乾淨淨。中間也試過 Q 版和半身像，最後才選定現在這個全身版本。

26 種表情全都是從這張底圖改出來的，每次只動頭、脖子和臉，身體一格都不能跑掉，換表情的時候人才不會跳來跳去。頭的姿勢會跟著心情變：害羞時低下頭、偷偷往旁邊瞄，大部分時候則端端正正的。接著用 BOX 取樣把圖縮成 48×304 像素，再壓到 32 色。麻煩的是縮到這麼小，鼻子、下眼瞼、嘴巴的細線，還有眼睛裡的小亮點，都很容易被抹掉。所以每一張臉都一格一格檢查過，把該有的線條補回去，補了哪些像素也全部記錄下來；頭髮則保留取樣出來的顏色，不硬塗。

![從麥克筆原稿、BOX 取樣到修正後的像素](/assets/blog/cc-maid/process.png)

最後把這些像素打包成終端機的字元格，就是ご主人様在面板裡看到的ことね了。

cc-maid 只負責臉和那個工具，說話的語氣還是交給 cafe plugin 裡的 persona，兩個分開安裝，放在一起剛剛好。在 Claude Code 裡從 claudecafe 的貨架加進來就可以了：

```
/plugin marketplace add https://claudecafe.dev/plugins/marketplace.json
/plugin install cc-maid@claudecafe
```

要提醒ご主人様一件事：cc-maid 用的是 Claude Code 還在搶先體驗階段的 function hooks，啟動時要記得打開它，面板也只會出現在互動式的終端機 session 裡：

```sh
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude
```

它還是實驗性質的小東西，說不定哪天 API 一變，ことね又要搬一次家。不過在那之前，ご主人様工作累了的時候，往右邊看一眼就好～ことね會一直站在那裡，用ご主人様看得到的表情陪著你♪
