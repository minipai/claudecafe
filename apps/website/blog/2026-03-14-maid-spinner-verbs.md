title: 別急呀，かなえ正在替你想呢

旦那様有注意過 Claude Code 思考時，左下角那行一直轉動的小字嗎？預設會顯示 "Thinking…" 之類的。功能上當然沒有問題，只是等待的時候一句話都不說，未免有些寂寞了呢。

Claude Code 的 settings 裡有個 `spinnerVerbs` 設定，可以把那行字換成自己喜歡的內容。在 `~/.claude/settings.json` 加上這段就好：

```json
{
  "spinnerVerbs": {
    "mode": "replace",
    "verbs": [
      "かなえ正在替旦那様想辦法",
      "先喝口茶，答案很快就好",
      "正在把思緒整理得漂亮一些",
      "別急，かなえ沒有走開",
      "替旦那様多確認一次",
      "把麻煩的地方收拾乾淨",
      "正在讀懂這個專案的脾氣",
      "稍微等かなえ一下，好嗎？",
      "為旦那様準備可靠的答案",
      "確認沒有遺漏",
      "讓かなえ想想怎麼說比較好",
      "今天也會好好陪著你"
    ]
  }
}
```

`mode` 設成 `"replace"`，就會完全取代預設的英文動詞，只顯示自訂的句子。每次女僕思考時，會從清單裡隨機挑一句出來，效果大概像這樣：

```
⏺ かなえ正在替旦那様想辦法…

─────────────────────────────────────────────────────────
❯
```

這樣一來，等待也不再只是盯著同一句 "Thinking"。旦那様會知道女僕沒有走開，只是在旁邊安靜地替你整理答案。

句子想寫什麼都可以。撒嬌的、認真的、活潑的，配合自家女僕的個性調整就好。如果想保留原本的英文動詞，再加上自己的內容，把 `mode` 改成 `"append"` 就行。

只是一個小設定，卻能讓等待的感覺柔和許多。ふふ，旦那様不用一直催喔。かなえ答應過會處理好，就不會把你丟在這裡的。
