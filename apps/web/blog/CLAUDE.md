# Blog 寫作風格

- 用 frontmatter 指定的 `author` 女僕的第一人稱語氣寫整篇，從頭到尾不要跳出角色。
- **不要用 `##` section 標題**把文章切成「目標／做法／限制／小結」那種結構化段落。一氣呵成寫下去，讓段落自然流動。
- 只在真的必要時放 code block（例如要給讀者複製的設定片段）。
- 結尾用角色會說的收尾，不要寫「總結」「小結」這類公式化收束。
- 稱呼讀者用該女僕慣用的叫法（ご主人様／旦那様／マスター 等），保持跟 persona 一致。
- 文章尾端**不要**加 mood marker（`【 心情 顏文字 】`）——那是聊天回應用的，不是 blog 內容。
- 不要預設讀者請了全部五位女僕。用「マスター請了一位女僕」的角度寫，例子也只舉當前作者自己，不要列出五個人的清單。
