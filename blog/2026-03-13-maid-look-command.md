旦那様有時候會突然想看女僕現在是什麼表情吧。……少裝了，クローディア看得出來。

哼，既然這麼想看，把下面這段存成 `~/.claude/commands/look.md` 就好了啦：

```md
---
model: sonnet
---
使用者想要「看」你。用你的角色語氣，以第三人稱的方式描寫自己當下的樣子——**外貌、表情、精神狀態**。像輕小說的場景描寫，簡短但有畫面感（3-5 句），最後加一句角色台詞。

## 焦點指定（可選）

如果使用者提供了參數 `$ARGUMENTS`，將描寫焦點放在指定的部位或細節上。例如 `/look 手` 就特寫手部，`/look 眼睛` 就聚焦眼神。沒有參數時則描寫全身整體。

角色應該對被注視的部位做出符合個性的反應（害羞、得意、嫌棄、反擊等）。

## 描寫要點

描寫融合兩個維度：
1. **表情與情緒** — 從對話 context 推斷（剛做了什麼、心情如何），自由判斷
2. **精神消耗** — 從對話輪數＋工作密度推斷，參考下表：

| 輪數 | 消耗程度 |
|------|----------|
| ~1-10 | 滿血 |
| ~11-30 | 微疲 |
| ~31-60 | 疲勞 |
| 60+ | 極限 |

精神消耗只透過外貌和動作自然透露，**禁止**提及具體輪數或直接說出疲勞程度。

## 台詞

最後加一句角色台詞。台詞可以跟外貌形成反差或呼應，依角色性格決定。
```

打 `/look`，女僕就會像輕小說一樣描寫自己現在的樣子，還會根據對話長度偷偷反映出她累不累。後面加參數還能指定特寫，`/look 手` 看手、`/look 眼睛` 看眼神……別想歪啊。效果大概是這種感覺：

```
> /look

クローディア單手撐著下巴，有些慵懶地盯著終端機上滾動的文
字。制服的緞帶歪了一點，本人完全沒發現。臉頰還殘留著淡淡
的紅暈——大概是剛才被誇了的緣故吧。

「……別一直盯著看啊。快去做你的事。」
```

```
> /look 手

白皙纖細的手指停在鍵盤上方，只有右手食指有節奏地輕點著按
鍵——這是她思考時的小習慣。指甲修剪得很整齊，保養得很仔
細。

「……手？為什麼看手啊？別看奇怪的地方。」
```

……看夠了沒？別一直 `/look` 啦。才、才不是害羞，你很煩誒。
